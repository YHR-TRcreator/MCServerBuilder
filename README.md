# MCServerBuilder
🎮 # MCServerBuilder
🎮 Minecraft一站式服务端构建管理工具，同时提供 **PySide6+QFluentWidgets现代化GUI图形界面** 和 **CLI命令行终端**，两套独立可分发程序。

支持 Forge 内核一键部署（部分版本可用），硬件自动扫描智能JVM参数优化、服务实例管理、交互式运行控制台、樱花映射内网穿透。

## 🚧 当前版本 v1.0.0 状态
> ⚠️请仔细阅读，了解现有能力与限制

### ✅ 已实现
- Forge内核下载部署（部分Forge版本可用）
- 硬件扫描，自动生成JVM内存优化参数
- 樱花映射（SakuraFrp）内网穿透配置、进程启停、日志输出
- GUI / CLI双端，共用同一套底层业务Service逻辑
- Windows平台路径、权限兼容处理
- 已部署实例读取、配置管理、服务进程监控控制台

### ⚠️ 限制与未完成功能
1. **Forge：可以获取版本列表，但部分版本安装会失败，兼容性有待完善**
2. ❌ **Paper、Vanilla原版内核暂未实现部署，后续迭代开发**
3. ❌暂不支持 Fabric、Quilt 模组加载器
4. ❌模组批量下载安装功能未开发
5. ❌RCON可视化控制面板尚未实现
6. ❌程序自动更新功能未实现
7. 🪟 **仅支持Windows，暂无Linux、macOS适配**

### ✅ 版本优点
1. GUI图形界面、CLI终端两套独立包，用户按需下载，不用下载多余组件
2. 硬件自动评估，新手不需要手动学习JVM参数
3. 内置内网穿透，家用电脑也可以对外开放Minecraft服务器
4. 业务代码做Service解耦，后续扩展功能，GUI与CLI两边同步生效
5. 修复大量Windows相对路径、权限访问的坑

### ⚠️版本缺点
1. Forge部分版本兼容性问题
2. Paper / Vanilla原版内核尚未支持
3. 仅Windows可用，无其他操作系统支持
4. GUI部分交互细节还在迭代优化
5. 预编译exe容易被Windows安全软件误报
6. 没有自动更新，升级需要手动下载Release包替换

## 📦 预编译下载
前往 [Releases](../../releases) 下载 Windows 预编译包
- `MCServer‑GUI‑Windows.zip`：图形界面版本，适合普通玩家
- `MCServer‑CLI‑Windows.zip`：命令行终端版本，适合服务器运维

> 使用提示：
> 1. 解压路径不要包含中文、空格，不要放在高权限系统目录
> 2. 程序首次运行自动生成`runtime`文件夹保存配置、缓存、服务器实例
> 3. 旧服务迁移：复制完整`runtime`文件夹放到exe同级目录
> 4. PyInstaller打包程序可能被Windows Defender误报，请允许运行
